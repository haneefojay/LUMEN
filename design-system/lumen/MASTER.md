## Global Tokens

### Color Palette

| Role | Hex | CSS Variable |
|------|-----|--------------|
| Void (Background) | `#0A0A0C` | `--bg-void` |
| Surface (Panels) | `#111116` | `--bg-surface` |
| Primary Accent (Bone) | `#E8D5B7` | `--color-bone` |
| Secondary Accent (Slate) | `#6C7A89` | `--color-slate` |
| Highlight (Muted Gold) | `#C9A96E` | `--color-gold` |
| Border / Subtle | `rgba(232, 213, 183, 0.12)` | `--color-border` |
| Border Hover | `rgba(201, 169, 110, 0.4)` | `--color-border-hover` |

### Typography

- **Heading Font:** Cormorant Garamond (Google Fonts)
- **Body Font:** Inter Tight (Google Fonts)
- **Mono Font:** JetBrains Mono (Google Fonts)

### Motion Tokens

- `--ease-reveal`: `cubic-bezier(0.16, 1, 0.3, 1)`
- `--ease-inertial`: `cubic-bezier(0.25, 1, 0.5, 1)`
- `--ease-snap`: `cubic-bezier(0.4, 0, 0.2, 1)`
- `--duration-hover`: `180ms`
- `--duration-reveal`: `1000ms`
