# Motion structure notes

The motionsites.ai custom MCP is not connected in this session. These are independent structural extractions from publicly accessible motion references, recorded so no prompt or template is copied.

## Pattern 01 — Occluded threshold
- **Structure:** void → focal object → oversized title behind object → catalogue UI in front.
- **Timing:** ambient motion starts immediately; title reveal waits for initial scroll; UI is present without entrance spectacle.
- **Scroll:** camera dollies slightly past the object while its silhouette uncovers the wordmark.
- **LUMEN adaptation:** seeded torus form occludes “LUMEN”; warm bone edge light replaces neon glow.

## Pattern 02 — Continuous camera handoff
- **Structure:** hero object exits frame on the same axis that introduces the manifesto.
- **Timing:** object translation, title clip, and manifesto line-spacing change share one scrubbed timeline.
- **Scroll:** no hard section cut; the camera pull-back creates negative space for text.
- **LUMEN adaptation:** the artifact recedes toward upper-right as manifesto lines arrive from the lower-left.

## Pattern 03 — Pinned specimen rail
- **Structure:** fixed canvas + horizontally translating catalogue chapters + persistent exhibit number.
- **Timing:** each object receives one 20–30% focus window; transitions overlap so no dead air appears.
- **Scroll:** vertical wheel input maps to camera X; mobile becomes vertical chapters with reduced geometry.
- **LUMEN adaptation:** Möbius, liquid cube, fractured sphere, and crystal each have a distinct material event rather than identical rotations.

## Curves and behavior selected
- Narrative clip reveal: `cubic-bezier(0.77, 0, 0.175, 1)`, 900–1200ms when time-driven.
- Enter/exit: `cubic-bezier(0.23, 1, 0.32, 1)`.
- Frequent hover/press: 180ms maximum.
- Ambient object rotation: frame-driven, extremely slow, paused offscreen.
- Particle drift: deterministic low-frequency curl-like field; no random jitter.
