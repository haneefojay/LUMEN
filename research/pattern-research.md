# Reference pattern research

Mobbin is not connected in the current tool surface, so this phase uses public award-gallery and product-pattern research rather than pretending a Mobbin query ran.

## Immersive hero
**Principle:** establish one visual sovereign. The object should cross the viewport crop and the title should occupy a different depth plane. LUMEN adapts this by placing the artifact right-heavy and the wordmark low-left, revealed through occlusion.

## Horizontal gallery
**Principle:** horizontal movement is justified when each stop is a room or specimen, not a carousel card. LUMEN pins the hall and maps vertical progress to camera X while preserving DOM chapters for accessibility.

## Portfolio navigation
**Principle:** navigation should expose orientation without competing with the work. LUMEN uses a four-line catalogue index and a progress trace; labels are direct anchors and remain instant for keyboard activation.

## Museum website
**Principle:** institutional confidence comes from catalogue systems, measured spacing, restrained materials, and precise identifiers. LUMEN borrows the authority, not the white-cube visual cliché.

## Footer / transition
**Principle:** the ending should resolve the spatial system, not launch a generic CTA band. The final artifact collapses into a point of warm light while credits remain typographically quiet.
